\# 📚 Snap \& Study



Snap \& Study is an AI-powered study assistant that helps students understand

study material from images.



\## ✨ Features



\- 📸 Upload a study image

\- 🤖 Get an AI-generated explanation

\- 📌 Understand the main topic and important points

\- 💬 Ask follow-up questions about the uploaded material

\- 📧 Send the AI explanation to an email address

\- 🔐 Keep API keys and passwords private using Streamlit secrets



\## 🛠️ Technologies Used



\- Python

\- Streamlit

\- Google Gemini API

\- Gmail SMTP

\- Google AI Studio
